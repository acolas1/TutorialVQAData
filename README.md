# TutorialVQAData
Data for our LREC 2020 paper [TutorialVQAData: Question Answering Dataset for Tutorial Videos](https://aclanthology.org/2020.lrec-1.670.pdf) paper. For the videos, here is a [mirror](https://archive.org/details/videos_202604) in case the original links don't work.
